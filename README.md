# 🕊️ 鸽子生态模拟 · 原鸽（*Columba livia*）三维建模

**在线体验：<https://liyucheng1997.github.io/pigeon-sim/>** · [模型检视](https://liyucheng1997.github.io/pigeon-sim/viewer.html)

一个在浏览器中运行的三维模拟：程序化精细建模的城市鸽子，按真实的生理需求与习性在广场上生活——觅食、吸吮式饮水、理羽、求偶、筑巢孵卵、哺育鸽乳、群飞、躲避天敌、黄昏归巢……

## 运行

需要 Python 3（只用来起一个本地静态服务器）。three.js（r170）已放在 `vendor/three/` 中，无需安装依赖。

```bash
python serve.py
```

然后在浏览器打开：

- 生态模拟：<http://localhost:8342>
- 模型检视（单只鸽子、各种姿态、羽色切换）：<http://localhost:8342/viewer.html>

> 不能直接双击 `index.html` 打开（ES 模块需要通过 http 加载）。

## 模型（`src/pigeon/PigeonModel.js`）

全部用代码生成，没有外部模型或贴图文件：

- **躯干**：按原鸽体型变形的曲面，胸部龙骨突前鼓，分区着色（背、胸、腹、腰部白斑、尾下覆羽），叠加鳞状体羽凹凸纹理。
- **颈部**：每帧重建的柔性管状曲面（贝塞尔中心线 + 平行传输标架），支持伸缩、点头、扭转近 180° 理羽、求偶时嗉囊鼓胀、吞咽波动；材质为物理薄膜干涉（iridescence），呈现随角度变化的绿/紫金属光泽。
- **头部**：前额斜向喙部，白色蜡膜（鼻瘤），上下喙（下喙可张合），橙红虹膜（带放射纹理、高光）、眼环和可开合的眼睑。
- **翅膀**：三段翼骨（肱骨、前臂、手部）+ 每侧 10 枚初级飞羽、11 枚次级/三级飞羽、大中小覆羽、初级覆羽、小翼羽、肩羽，每侧约 67 片独立羽毛；收拢时按真实的“Z”字形折叠，并切换为绘有鳞状覆羽和两道黑色翼斑的贴体翼面；翼下颜色更浅。
- **尾**：12 枚尾羽（黑色次端带、外侧尾羽白色外翈）+ 尾上/尾下覆羽，可扇形展开、上下摆动。
- **腿脚**：被羽的胫部、带盾鳞纹理的红色跗跖、三前一后四趾（每趾两节 + 角质爪），两骨 IK 让脚掌贴地不打滑，趾可蜷曲抓握。
- **羽色型**：灰色双斑（野生型）、雨点、灰红、黑（spread）、纯白、花斑；雄鸽略大、蜡膜和颈部光泽更明显；幼鸽几乎没有金属光泽。

性能：每只鸽子的 150 余片羽毛、趾节等小零件在 CPU 上合并成少数几个网格（`RigidBatch.js`），视锥外和远处的鸽子按距离分级降低重建频率。

## 习性建模

行为由**效用 AI**（`Brain.js` + `Behaviors.js`）根据需求打分选择，需求由生理模型（`Pigeon.js`）驱动：

- **生理**：能量储备、嗉囊（容量约 22 g，按约 3 g/h 排空消化）、水分、精力、羽毛整洁度、恐惧、孤独、繁殖驱力、体温（冷时蓬羽）；心率（静息约 200、飞行约 600 次/分）、呼吸随活动变化。基础代谢按游戏时间计，飞行等活动按实际持续时间计。
- **行走**：双足交替迈步，头部先在空间中“定住”再前冲——即走路点头。
- **觅食**：低头搜寻、啄食（啄击末段闭眼）、整粒吞入嗉囊、吞砂砾；被撒食的老人和正在觅食的同伴吸引（局部增强）；抢食时高等级个体啄赶低等级个体。
- **饮水**：喙浸入水中连续吸吮，不抬头。
- **维护**：理羽（翼覆羽、胸、翼下、背/尾、飞羽）、水浴后抖羽、日光浴（侧卧张翅）、单侧翼腿伸展、午间小憩（单脚站立或伏卧）。
- **社会与繁殖**：雄鸽栖鸣、鞠躬咕咕、拖尾转圈、追逐雌鸽；雌鸽接受度逐渐上升后结为终生伴侣；亲吻（喂吻）、互相理羽；选壁龛为巢址，雄鸽衔枝、雌鸽坐巢整理；2 枚卵间隔约 44 小时；雄鸽约 10:00–16:30、雌鸽其余时间轮班孵卵，换班时在巢边等候；约 17.5 天孵化，双亲用鸽乳哺育，约 28 天出飞并成为鸽群新成员。
- **警戒与逃避**：伸颈侧眼盯视；人走近到惊飞距离（小孩冲过来比路人更可怕）就起飞，拍翅声引起同伴连锁惊飞（有传播层数与不应期）；遇游隼全群紧密盘旋后落到屋檐。
- **飞行**：起飞（高频大幅振翅、翼尖拍击）、巡航（振翅与短滑翔交替，转弯侧倾）、雄鸽 V 形炫耀滑翔、进近、拉平着陆（尾羽全张、双腿前伸）；鸽群定时绕楼盘旋。
- **昼夜节律**：日出后飞下广场，黄昏回到固定的窗台栖位过夜，头缩进羽毛中睡觉。

## 代码结构

```
index.html / styles.css      生态模拟页面
viewer.html                  模型检视页面
serve.py                     本地开发服务器（禁用缓存）
vendor/three/                three.js r170 及用到的两个扩展（MIT 许可）
src/
  main.js                    渲染器、主循环、交互、随机事件
  viewer.js                  模型检视
  config.js                  生物学参数与鸽群初始设定
  pigeon/
    PigeonModel.js           程序化模型（骨骼、羽毛、颈部、翼面）
    RigidBatch.js            小零件合批
    Plumage.js               羽色型
    PigeonAnimator.js        程序化动画：步态 IK、点头、振翅、啄击、眨眼、呼吸
    Poses.js                 姿态库
    Pigeon.js                个体：生理、感知、步行与飞行控制
    Brain.js                 效用 AI 决策
    Behaviors.js             各种习性行为
    Flock.js                 鸽群、配对与繁殖、惊飞传播、群飞
  world/                     昼夜、广场与楼房、食物、巢、老人/路人/游隼
  audio/Sounds.js            WebAudio 合成声音
  ui/                        信息面板与习性百科
```

调试：在浏览器控制台中可以用 `app.force('灰灰', 'preen')` 让指定鸽子立即执行某个行为，用 `app.simulate(秒数)` 快速推进模拟。

## 简化与取舍

- 为了在广场尺度内看得清，飞行速度按 0.55 缩放（真实平飞约 60–80 km/h）。
- 时间被压缩（默认一天约 12 分钟），而动作本身按真实速度播放，因此个体一天里做的事情比真实鸽子少；孵卵、育雏等以“天”为单位的过程可以用“+1 天”跳跃观察。
- 交配行为只表现到亲吻为止。
